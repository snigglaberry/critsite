# regarding safety

## malware protection
crit launcher is completely opensource, and has never had malware at any point since its creation
all 3rd party pr requests are checked for malware
as of right now sha256 signing has been added to crit to prevent any 3rd party attacks


## tracking
crit does not track any user data EXCEPT curseforge api data usage
curseforge api usage is monitered to prevent spam and overusage of the api
any tracking by modrinth or curseforge is not our concern
